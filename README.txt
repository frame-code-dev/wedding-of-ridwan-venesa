UNDANGAN WEDDING VENESA & RIDWAN

File:
- index.html = halaman utama
- style.css = desain
- script.js = countdown + WhatsApp RSVP
- assets/musik.mp3 = opsional, masukkan lagu sendiri

YANG PERLU DIGANTI:
1. Nama orang tua di index.html pada bagian [Nama Ayah] / [Nama Ibu].
2. Nama gedung dan alamat akad/resepsi.
3. Link Google Maps pada href="https://www.google.com/maps".
4. Nomor WhatsApp RSVP di script.js pada const phone.
5. Jika ingin musik, masukkan file musik.mp3 ke folder assets.

DESAIN:
Tidak membutuhkan foto wedding. Desain memakai monogram VR, ornament floral, gold/cream, countdown, lokasi, RSVP dan cerita.
